# HTML + Tailwind starter

A static site in plain HTML, Tailwind CSS and JavaScript, with no build step.

## Run it

Serve the folder with any static server. For a page that reloads on save:

```bash
npx live-server
```

## Deploy

Upload the folder as-is to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

Tailwind runs in the browser from its CDN script, which suits prototypes and small sites. For production traffic, compile the CSS ahead of time with the Tailwind CLI instead.
